# Practical Orchestrator — profile summary

Purpose: automatic, economical subagent routing for everyday Codex work.

Modes:
- SIMPLE — primary-first, normally no subagents.
- STANDARD — default, normally 0–2 useful subagents, optional one focused reviewer.
- DEEP — explicit/high-risk work, multiple evidence lanes allowed, one FULL + at most one normal DELTA review.

Design principle: a subagent should normally replace primary research, not duplicate it.

This file is explanatory only. Normative rules are in `AGENTS.md` and `docs/agent_guides/`.
