# Решение

Режим STANDARD, без делегирования. Парсер принимает вес первым, включая десятичные
значения; предварительный фильтр Telegram допускает десятичный вес. Вывод результата,
отмены и истории использует явный формат «вес кг × повторы». Оценки easy/normal/hard
отображаются как легко/норм/тяжело; отсутствующая оценка не выдумывается.
Существующий выбор исторического результата не меняется. Markdown экспортирует вес
первым, включая особые единицы farmer carry; именованные поля JSON сохраняются.
Проверка: тесты парсера, Telegram, истории, экспорта и полный pytest. Baseline по
предыдущему завершённому изменению: 122 теста PASS; локальный предварительный запуск
не выполнен. Миграция и новые зависимости не требуются.

Проверки: полный pytest — 125 PASS за 56,77 с. После добавления проверки Telegram
и перестановки полей JSON повторно запущены тесты экспорта и Telegram: 43 PASS
за 26,74 с. `git diff --check` прошёл. Первый запуск после изменения формата
обнаружил зависимость теста импорта от окончания строк YAML; исходный формат
файла восстановлен. Реальный Telegram и Docker не проверялись. Проверен выбор
истории с тремя вариантами оценки и отсутствие оценки в существующих сценариях.
