# MVP тренировочного бота

Нужен короткий цикл записи силовых подходов в закрытой Telegram-группе:
подсказка → подход → `8*50` → следующая подсказка. Сейчас кода нет.

Реализовать требования разделов 3–25 `1st_prompt.md`: настройку группы,
самостоятельные привязки, атомарный импорт YAML, общую тренировку с
индивидуальным прогрессом, историю, навигацию и восстановление из SQLite.
Поставить приложение в одном контейнере с инструкцией оператору.

Non-goals из раздела 2 остаются вне области работ. Деплой на удалённую
машину и реальные операции Telegram не входят в локальную реализацию.

Приёмка: два спортсмена независимо записывают подходы, повтор сообщения
не создаёт дубль, состояние переживает повторное открытие БД, неверный
чат/непривязанный пользователь не записывает результат. Чистая установка,
миграции, тесты и документированный запуск соответствуют разделу 25.
